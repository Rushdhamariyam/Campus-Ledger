# Campus Ledger

Campus Ledger is a Flask-based student finance and campus event management system designed for students and administrators.

## Features

- Student login and dashboard
- Admin dashboard
- Event management
- Club pages
- Token system
- Student profile management
- Responsive web interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
